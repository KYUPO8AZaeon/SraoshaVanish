# SRAOSHA VANISH

Thumby version 0.11.1 — Created by AZ-aeon. Original world and characters: AEON.

A monochrome arcade puzzle set in the original world of AEON.
Choose 3 ammunition types from 5 candidates to match enemy weaknesses and aim for a high score.

## Install on Thumby

Copy the `SraoshaVanish` directory to `/Games/` on your Thumby using the Thumby Code Editor.
The executable must be `/Games/SraoshaVanish/SraoshaVanish.py`.
Keep all 100 BIN files and `catalog_text.dat` in the same directory as the executable.
The PNG and text files used for the Arcade listing are not required to run the game.

When upgrading from the development directory `SraoshaUI`, transfer the entire new directory.
The high-score save name remains `SraoshaVanish`; the save key is unchanged.
